로그 추출 4단계 가이드

갤럭시 기본 전화 앱과 내 파일 앱을 이용해 추출합니다.

1
SysDump 진입 코드 실행
전화 앱에서 *#9900#을 입력합니다.
📞 전화 앱 열기
2
로그 생성
메뉴 최상단의 Run dumpstate/logcat을 누르고 1~2분 뒤 "Dump Result" 팝업이 뜨면 [OK]를 누릅니다.
3
저장공간 복사
아래쪽의 Copy to sdcard를 누릅니다. (복사 완료 창이 뜰 때까지 대기)
4
웹앱에서 파일 선택
하단 [파일 선택]을 누른 뒤 내장 저장공간 > log 폴더의 dumpState_*.log 파일을 선택합니다.
