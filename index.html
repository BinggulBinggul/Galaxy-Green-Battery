로그 추출 5단계 가이드

정확한 분석을 위해 아래 순서대로 진행해 주세요.

1
보안 위험 자동 차단 해제 (필수)
켜져 있으면 다이얼 코드 진입이 차단됩니다.
1. 화면 맨 위를 쓸어내려 톱니바퀴(⚙️ 설정) 터치
2. 상단 돋보기(🔍)에 아래 복사한 단어를 붙여넣고 [사용 안 함]으로 꺼주세요!
2
SysDump 코드 실행
전화 다이얼 패드에서 *#9900#을 입력합니다.
📞 전화 다이얼 열기
3
로그 생성
메뉴 맨 위의 Run dumpstate/logcat을 누르고 1~2분 뒤 "Dump Result" 팝업이 뜨면 [OK]를 누릅니다.
4
저장공간 복사
아래쪽의 Copy to sdcard를 누릅니다. (복사 완료 알림이 뜰 때까지 대기)
5
메인 덤프 파일 선택 (중요!)
내장 저장공간 > log 폴더 안에서 dumpstate_board.log가 아닌 용량이 가장 큰 dumpState_[모델명]...log를 선택하세요!
